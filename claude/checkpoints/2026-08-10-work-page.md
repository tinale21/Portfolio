# Checkpoint — Work page (case study listing)

## Context

Built the `/work` listing page from scratch: a grid of case-study thumbnails (reusing the homepage's existing project videos) plus two non-clickable "NDA" placeholder cards, driven by a Figma prototype video the user recorded.

## Human directions

- "this is to showcase my case studies for different projects... these thumbnails are videos i will provide you (they are actually the same video you used on the selected projects page if you still have access to them). I also have two other projects there that are under NDA... here is a video of my figma prototype" — gave a screen recording as the primary spec, not static images.
- Asked two clarifying questions before building: what "Previously at [logo]" should show, and how to handle the two NDA cards' custom background art. Answers: "it is the existing logo svg you used for the logo scroll, the logo should appear and change one at a time here" and "ill send the images that you could build from if that's better".
- Sent the Delta and GICC background images later, plus two Figma "Fill" panel screenshots showing the exact tint technique (a plain black fill at 59% opacity layered over the image).
- "can you double check to make sure the text size and bubble for emora and framer redesign match the text size and bubble size used for aig and wayve" — a request to verify, not a bug report.
- Sent Figma dev-mode CSS for "My Work" (Inria Serif 36px/400) and "Previously at" (Inter 20px/200, #6D6B6B, 746px fixed width) after my first-pass values (40px/bold, unstyled paragraph) turned out not to match.
- "can you make the nda a little bit bigger for the delta and gicc"
- "for the gicc it should be just GICC not GICC x SCADpro for the bubble"
- "can you change the [Explorer caption] to 'City views hit different' / 'in Chicago.'" (a leftover from the About page's earlier photo swap — the caption still referenced the old Washington Monument photo).
- "lets build and push".

## Records of resistance / things I got wrong and had to correct

- **Analyzed the Figma prototype video the same way as the About page's motion reference** (extracted frames, read pixel positions/timing) rather than asking the user to describe the layout in words — this is what surfaced that Framer Redesign/Emora's cards aren't a special "icon-centered" treatment, they're just the *same* `ProjectCard` component playing video files whose actual content happens to be an icon reveal on a plain background. Confirmed this by checking the existing `emora.mp4`/`framer-redesign.mp4` file sizes (43-220KB, consistent with a short icon animation) against `wayve.mp4` (1.1MB, a fuller motion graphic) before committing to that interpretation.
- **Verification-by-question, not just eyeballing**: when asked to "double check" the badge sizing across all four project cards, measured actual `getBoundingClientRect()`/computed-style values via Puppeteer for each rather than just re-reading the shared component's source and asserting it must be fine — confirmed byte-for-byte identical height/padding/font-size/weight across all four, with only badge *width* differing (expected, since names differ in length).
- **Got the two new heading text styles wrong on the first pass** (guessed 40px/bold for "My Work", left "Previously at" with no explicit size/weight at all) — corrected once given literal Figma dev-mode CSS, verified the fix landed via computed-style measurement rather than trusting the diff alone.
- **Reused the ALREADY-CONFIRMED tint technique from the About page's earlier `2026-08-08` NDA... no — this was actually new to this page**: when the user's Figma "Fill" panel screenshots showed a black-59%-over-image layer structure, implemented it literally as a solid black div at `opacity-[0.59]` stacked on top of the `<Image>`, rather than approximating with a CSS filter (grayscale/brightness) that wouldn't match the same math.

## Successes

- Didn't try to guess the "Previously at" treatment or invent NDA card artwork from a blurry video frame — asked two focused, specific questions up front (not a vague "what should this look like?"), which is what surfaced the actual mechanic (a cycling logo, not a static one) that a screenshot-based guess would have missed entirely.
- Every "does this match" claim (badge sizing consistency, new heading typography, tint opacity) was settled by reading actual computed values via Puppeteer, continuing this project's established discipline rather than reverting to eyeballing once the work moved to a new page.
